# ITP · Image to Pose & 3D

国内服务优先的角色姿势控制与 3D 资产工作台。参考 Meshy Custom Pose 视频，支持角色图、姿势参考图、多视角、几何生成、拓扑、PBR、绑骨与资产导出。

## 实施状态

项目正在按 [实施计划](docs/PLAN.md) 开发。真实云端效果必须用用户自己的服务凭据和测试图片验收；没有凭据时不会伪造模型结果。
