# Web 工作台

前端位于 `frontend/`，使用 React、TypeScript、Vite、Three.js。构建资源打包到 `frontend/dist/` 后由 FastAPI 本地提供；运行时不依赖境外 CDN。开发服务器使用 Vite 的本地 `/api` 代理。默认服务仅绑定回环地址。

## 页面与交互

工作台左侧上传角色、姿势、多视角并选择生成步骤；中间显示 GLB 预览与每阶段产物；右侧显示服务配置状态与任务历史。左侧导航的设置页可填写腾讯云和千问服务地址、模型与凭据，保存后立即生效。历史页从本地 SQLite 读取任务，不调用外部系统。已上传图片显示预览，去背景开关仅影响后续上传。

点击“开始生成”会列出尚缺的角色图、姿势参考图、服务配置或绑骨确认项。已上传图片可点击放大，另有更换与移除按钮。设置页提供森林绿、海洋蓝、暖日橙、暮光紫配色和标准、高对比度选项；外观选择只保存在浏览器本地。常见云端错误码显示中文排查建议，同时保留原错误码与 RequestId。

如果未配置云端 API，上传、预处理和本地 GLB 导入可用，生成按钮显示“生成服务待配置”。姿势编辑阶段结束后，用户须确认或放弃姿势图。未确认前，3D 阶段不会启动。

Three.js 预览只接受自包含 GLB。导入用户文件或服务返回的 GLB 后自动居中、归一化尺寸，支持旋转、缩放、线框视图。OBJ、FBX、ZIP 均提供真实文件下载，当前预览器不解析这些格式；附加外部纹理引用、Draco 等压缩扩展也未实现。

前端每 3 秒查询任务列表，页面关闭后停止定时器。较大模型载入、WebGL 不可用和格式错误会给出提示；模型场景与 GPU 资源在组件卸载时释放。空白场景中的线框立方体仅为视觉指示，不表示生成了模型。

## 构建与测试

前端锁文件 `package-lock.json` 固定安装版本，`npm ci` 用于复现；`npm run build` 会先进行 TypeScript 检查。Playwright 在桌面和手机视口覆盖未配置状态、图片上传、姿势模式切换、本地 GLB 导入、任务历史和配置面板。真实任务审核与产物下载仍需云端账号联调。

密钥由后端写入并读取本地 `.env`，网页在保存时发送输入的密钥，不保存到浏览器存储，也不读取已保存的密钥。工作台是本机单用户应用；外网部署需要认证、配额、隔离和新的跨域策略。
