# 图片预处理模块

实现：`src/itp/preprocessing.py`。输入 PNG/JPEG/WebP 字节流，输出去元数据的 RGBA PNG。限制 10 MiB、最小短边 128、总像素不超过 2500 万；拒绝动态图。解码完成后 EXIF 转正，最长边缩至 1024；缩放后短边小于 129 的极端长宽比不接受。

本地保存透明 PNG；模型请求时在白底上合成并 JPEG 编码，防止透明区域变黑，同时控制多图请求大小。用户文件名不用作路径；数据库使用随机 ID，文件读取仅通过该 ID。

## 去背景

U²-NetP ONNX 使用 CPUExecutionProvider 和两个推理线程，加载一次，推理通过锁串行。输入为 320×320 RGB，按上游归一化；输出掩膜还原至图像尺寸，并与原 alpha 取最小值。极差掩膜不自动宣称成功重建，用户可在预览中判断分割效果。

权重位于 `models/u2netp.onnx`，4,574,861 字节。SHA-256：`309c8469258dda742793dce0ebea8e6dd393174f89934733ecc8b14c76f4ddd8`。推理前校验上游 MD5。权重缺失时返回明确错误，不能隐式下载。

## 已知限制

小模型不保证复杂发丝、透明衣物、相似背景、强遮挡的高质量分割。多视角应先保证物体尺度、姿态和身份一致，不能用图像增强来掩盖信息缺失。首版没有自动超分、人体关键点抽取或相机标定。
