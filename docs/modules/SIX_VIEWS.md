# 六视图图生 3D

输入顺序为正面（必填），背面、左侧、右侧、左前 45°、右前 45°（均可选）。前端上传后取得本地资产 ID；提交 `POST /api/jobs` 时将正面放在 `front`，其余放在 `views`，并设置 `views_consistent_confirmed: true`。服务端验证视角枚举、资产存在、用户同人同服同姿势确认、总图片大小和模型版本。原来的单图、四视图及姿势编辑流程保持不变。

当前默认几何供应商为腾讯云混元 3D 专业版 3.1。正面作为 `ImageBase64`，其他角度作为 `MultiViewImages` 传入，3.1 接受 `left_front` 和 `right_front`；3.0 不接受这两个角度并返回 422。多图仍需用户确认一致性：确认框不是自动图像一致性识别，模型也无法保证绝对一致。编码前原图总量限制为 6 MiB，避免超过腾讯接口编码后 8 MiB 预算；具体限制以腾讯控制台为准。

接口依据：[腾讯云提交混元生 3D 专业版任务](https://cloud.tencent.com/document/product/1804/123447)。
