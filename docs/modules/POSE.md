# 姿势控制模块

支持 original / a-pose / t-pose / custom。自定义模式需要第二张姿势参考图；A/T 模式依赖角色图片与编辑指令生成中性姿态图。

## 过程

1. 用户上传角色图；自定义模式再上传姿势图。
2. 千问多图编辑：图一提供身份和服装，图二只提供肢体姿势。
3. 返回图在本地保存，任务进入 `awaiting_review`。
4. 用户检查身份、衣服、四肢、遮挡和完整性；确认后才调用混元 3D。
5. 放弃后进入 `rejected`，不继续调用 3D；已经发生的姿势编辑费用不会自动退回。

修改姿势时禁止携带原姿势的侧/背视图，避免将互相矛盾的图像送入多视图模型。界面切换时清空这些输入，后端同样验证。

这条路线不是 Meshy 未公开的内部姿势算法复现，也不是几何骨骼的硬约束。图像编辑可能产生身份漂移、额外肢体或姿态偏差；人工审核与实际样例评测是交付前必需步骤。首版不支持逐关节拖拽编辑、姿态检测指标或骨骼重定向。
