# 几何生成模块

首版调用 Tencent AI3D Pro，采用 `GenerateType=Geometry` 生成白模，并将纹理放在后续独立阶段。输入至少一张正面角色图，可选 left/right/back，同视角最多一张。

UI 提供 3 万、10 万、50 万、150 万目标面数；API 支持 3000～1500000 的整型值。面数是供应商目标参数，不保证返回精确数量。Model 默认 3.1，版本由服务端账号支持情况决定。

图像编码、特征融合、3D 表示预测、网格提取属于供应商内部；首版不伪造 Image Encoder、Meshy 7 或内部神经网络架构的本地实现。也不将程序生成的球/立方体当作图生 3D 结果。

返回产物优先选择 GLB 作为后续处理源，其次 OBJ。每阶段模型先落盘再进入下一阶段。GLB 文件头做基础校验，ZIP 以真实归档格式保存，不直接当 OBJ/GLB。

未来本地 Hunyuan3D backend 需定义独立推理环境、GPU 调度、权重版本与许可、资源预算和质量验收，不能直接在现有 API 进程中加载重型 CUDA 依赖。
